# 🎙️ 우리 목소리 책 (voice-book)

엄마·아빠 목소리로 아이에게 그림책을 읽어주는 **홈화면 앱(PWA)**.
설치 없이 브라우저에서 열리고, **녹음·저장·재생이 모두 이 기기 안에서만** 이뤄진다(서버 없음).

> 이 저장소는 '우리 목소리 책' **전용 저장소**다. (긴주 놀이터와 분리됨)

## 무엇을 하나
- 미리 준비된 동화·잠자리 이야기 목록에서 하나 고르기 (명작동화 + 포근한 잠자리 이야기)
- 대본을 보면서 **엄마/아빠 목소리로 녹음** → 이 기기에 저장 (최대 5분)
- 저장된 목소리로 **아이에게 들려주기(재생)**
- 다시 녹음 / 파일로 내려받기(안전 사본) / 불러오기 / 지우기

## 공개 주소
- **정식 주소 (Netlify, 공유용):** https://voice-book.netlify.app/
- (참고) GitHub Pages 백업 주소: `https://minjung9767-gif.github.io/voice-book/`

두 주소 모두 이 저장소 `main` 브랜치에 반영되면 자동으로 새로 배포된다.
사람들에게 공유할 때는 **Netlify 주소**를 쓴다(계정 이름·저장소 이름이 안 드러남).

폰에서 열고 **"홈 화면에 추가"** 하면 앱 아이콘처럼 쓸 수 있다.

## 저장 방식 (중요)
- 녹음은 브라우저의 **IndexedDB**에 저장된다 → 목소리 파일이 기기 밖으로 나가지 않는다.
- 그래서 **브라우저 기록을 지우거나 다른 기기로 가면** 녹음은 함께 가지 않는다.
- 걱정되면 각 녹음의 **"내려받기"**로 파일 사본을 폰에 보관해두면 된다.

## 파일 지도
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 (홈 · 이야기 화면) |
| `style.css` | 스타일 (따뜻한 색, 큰 버튼, 모바일 우선) |
| `app.js` | 녹음/저장(IndexedDB)/재생/내려받기 로직 |
| `scripts-data.js` | 대본 목록 — 새 이야기는 여기에 추가 |
| `manifest.webmanifest` | 홈화면 앱(PWA) 정보 |
| `sw.js` | 서비스워커 (오프라인 · 설치). 크게 고치면 `CACHE` 버전 숫자 올리기 |
| `icons/` | 앱 아이콘 (+ `gen_icons.py` 로 다시 생성 가능) |

## 확인 방법
카메라·마이크는 `file://`(파일 더블클릭)로는 안 되고 **https 또는 localhost**에서만 된다.
```bash
# 저장소 최상위에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/voice-book/ 열기
```

## 새 이야기 추가하기
`scripts-data.js` 의 배열에 항목을 하나 더 넣으면 된다(`id` 는 겹치지 않게):
```js
{ id: "my-story", title: "제목", emoji: "⭐", lines: ["첫 줄", "둘째 줄"] }
```
